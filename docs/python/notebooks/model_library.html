Precomputed Library#

CRO provides a library of precomputed RO parameter sets estimated from observational and climate model datasets. The library currently includes parameter sets fitted to the ORAS5 reanalysis and 48 CMIP6 historical simulations.

The parameter library is based on the following variable definitions:

  • T: detrended SST anomalies averaged over the Niño3.4 region (5°S–5°N, 170°–120°W)

  • h: detrended thermocline depth (20°C isotherm) anomalies averaged over the equatorial Pacific (5°S–5°N, 120°E–80°W)
