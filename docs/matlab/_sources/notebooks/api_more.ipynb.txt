        "### `RO_type`\n",
        "\n",
        "Eight predefined parameter-library RO types are supported:\n",
        "\n",
        "1. `Linear-White-Additive`\n",
        "2. `Linear-White-Multiplicative`\n",
        "3. `Nonlinear-White-Additive`\n",
        "4. `Nonlinear-White-Multiplicative`\n",
        "5. `Seasonal-Linear-White-Additive`\n",
        "6. `Seasonal-Linear-White-Multiplicative`\n",
        "7. `Seasonal-Nonlinear-White-Additive`\n",
        "8. `Seasonal-Nonlinear-White-Multiplicative`\n",
        "\n",
        "Their equations are:\n",
        "\n",
        "**Linear-White-Additive**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=RT+F_1h+\\sigma_Tw_T,\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "**Linear-White-Multiplicative**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=RT+F_1h+\\sigma_Tw_T(1+BT),\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "**Nonlinear-White-Additive**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=RT+F_1h+b_TT^2-c_TT^3+d_TTh+\\sigma_Tw_T,\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h-b_hT^2+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "**Nonlinear-White-Multiplicative**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=RT+F_1h+b_TT^2-c_TT^3+d_TTh+\\sigma_Tw_T(1+BT),\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h-b_hT^2+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "**Seasonal-Linear-White-Additive**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=\n",
        "\\left(R+R_a\\sin(\\omega t+\\phi_a)\\right)T+F_1h+\\sigma_Tw_T,\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "**Seasonal-Linear-White-Multiplicative**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=\n",
        "\\left(R+R_a\\sin(\\omega t+\\phi_a)\\right)T+F_1h+\\sigma_Tw_T(1+BT),\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "**Seasonal-Nonlinear-White-Additive**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=\n",
        "\\left(R+R_a\\sin(\\omega t+\\phi_a)\\right)T\n",
        "+F_1h+b_TT^2-c_TT^3+d_TTh+\\sigma_Tw_T,\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h-b_hT^2+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "**Seasonal-Nonlinear-White-Multiplicative**\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=\n",
        "\\left(R+R_a\\sin(\\omega t+\\phi_a)\\right)T\n",
        "+F_1h+b_TT^2-c_TT^3+d_TTh+\\sigma_Tw_T(1+BT),\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h-b_hT^2+\\sigma_hw_h.\n",

        "## `RO_solver_analytic`\n",
        "\n",
        "Analytical trajectory solution for the linear-white-additive RO."
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "### Syntax"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "[T, h] = RO_solver_analytic(par, IC, N, NE)\n",
        "[T, h] = RO_solver_analytic(par, IC, N, NE, dt)\n",
        "[T, h] = RO_solver_analytic(par, IC, N, NE, dt, saveat)\n",
        "[T, h] = RO_solver_analytic(par, IC, N, NE, dt, saveat, savemethod)\n",
        "[T, h] = RO_solver_analytic(par, IC, N, NE, dt, saveat, savemethod, noise_custom)\n",
        "[T, h, noise] = RO_solver_analytic(...)"
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "### Description and inputs\n",
        "\n",
        "`RO_solver_analytic` returns analytical trajectories of `T` and `h` for the linear-white-additive RO.\n",
        "\n",
        "`par` is the standard 16-element parameter cell array. All elements are scalar, but only\n",
        "\n",
        "- `R`\n",
        "- `F1`\n",
        "- `F2`\n",
        "- `epsilon`\n",
        "- `sigma_T`\n",
        "- `sigma_h`\n",
        "\n",
        "are used. The remaining entries may be unused values such as `[]` or `NaN`.\n",
        "\n",
        "Other inputs:\n",
        "\n",
        "- `IC`: `[T0, h0]`\n",
        "- `N`: simulation length in months\n",
        "- `NE`: number of ensembles\n",
        "- `dt`: numerical time step in months (default `0.1`)\n",
        "- `saveat`: output interval (default `1.0`)\n",
        "- `savemethod`: `\"sampling\"` or `\"mean\"` (default `\"sampling\"`)\n",
        "- `noise_custom`: scalar seed or `(NT-1)×4` noise matrix\n",
        "\n",
        "For `noise_custom`, only the first two columns are used by the analytical linear-white-additive solution; columns 3–4 are retained only for consistency with `RO_solver`. User-specified noise must be Gaussian white noise with zero mean and unit variance. The same supplied realization is used for each ensemble member."
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "### Outputs\n",
        "\n",
        "- `T`: `NT×NE`\n",
        "- `h`: `NT×NE`\n",
        "- `noise`: `(NT_internal-1)×4×NE`\n",
        "\n",
        "### Analytical solution\n",
        "\n",
        "The linear-white-additive RO is\n",
        "\n",
        "$$\n",
        "\\frac{dT}{dt}=RT+F_1h+\\sigma_Tw_T,\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{dh}{dt}=-F_2T-\\varepsilon h+\\sigma_hw_h.\n",
        "$$\n",
        "\n",
        "With initial conditions $T_0$ and $h_0$, define\n",
        "\n",
        "$$\n",
        "\\lambda_r=\\frac{R-\\varepsilon}{2},\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\omega=\\frac{\\sqrt{4F_1F_2-(R+\\varepsilon)^2}}{2}.\n",
        "$$\n",
        "\n",
        "Then\n",
        "\n",
        "$$\n",
        "\\begin{aligned}\n",
        "T(t)=e^{\\lambda_rt}\\Bigg[\n",
        "&T_0\\left(\\cos\\omega t+\\frac{R+\\varepsilon}{2\\omega}\\sin\\omega t\\right)\n",
        "+h_0\\frac{F_1}{\\omega}\\sin\\omega t \\\\\n",
        "&+\\int_0^t e^{-\\lambda_r\\tau}\n",
        "\\left\\{\n",
        "\\sigma_Tw_T(\\tau)\\cos[\\omega(t-\\tau)]\n",
        "+\\sigma_Tw_T(\\tau)\\frac{R+\\varepsilon}{2\\omega}\\sin[\\omega(t-\\tau)]\n",
        "+\\sigma_hw_h(\\tau)\\frac{F_1}{\\omega}\\sin[\\omega(t-\\tau)]\n",
        "\\right\\}\\,d\\tau\n",
        "\\Bigg],\n",
        "\\end{aligned}\n",
        "$$\n",
        "\n",
        "and\n",
        "\n",
        "$$\n",
        "\\begin{aligned}\n",
        "h(t)=e^{\\lambda_rt}\\Bigg[\n",
        "&-T_0\\frac{F_2}{\\omega}\\sin\\omega t\n",
        "+h_0\\left(\\cos\\omega t-\\frac{R+\\varepsilon}{2\\omega}\\sin\\omega t\\right) \\\\\n",
        "&+\\int_0^t e^{-\\lambda_r\\tau}\n",
        "\\left\\{\n",
        "\\sigma_hw_h(\\tau)\\cos[\\omega(t-\\tau)]\n",
        "-\\sigma_hw_h(\\tau)\\frac{R+\\varepsilon}{2\\omega}\\sin[\\omega(t-\\tau)]\n",
        "-\\sigma_Tw_T(\\tau)\\frac{F_2}{\\omega}\\sin[\\omega(t-\\tau)]\n",
        "\\right\\}\\,d\\tau\n",
        "\\Bigg].\n",
        "\\end{aligned}\n",
        "$$"
      ]
    },

        "## `RO_std_analytic`\n",
        "\n",
        "Analytical equilibrium standard deviations for the linear-white-additive RO."
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "### Syntax"
      ]
    },
    {
      "cell_type": "code",
      "execution_count": null,
      "metadata": {},
      "outputs": [],
      "source": [
        "[T_std, h_std] = RO_std_analytic(par)"
      ]
    },
    {
      "cell_type": "markdown",
      "metadata": {},
      "source": [
        "### Description\n",
        "\n",
        "`RO_std_analytic(par)` returns the analytical standard deviations of `T` and `h` for the linear-white-additive RO.\n",
        "\n",
        "`par` is the standard 16-element scalar parameter cell array.\n",
        "\n",
        "### Outputs\n",
        "\n",
        "- `T_std`: scalar standard deviation of `T`\n",
        "- `h_std`: scalar standard deviation of `h`\n",
        "\n",
        "### More about\n",
        "\n",
        "The second-order moments satisfy\n",
        "\n",
        "$$\n",
        "\\frac{d\\langle T^2\\rangle}{dt}\n",
        "=\n",
        "2R\\langle T^2\\rangle\n",
        "+2F_1\\langle Th\\rangle\n",
        "+\\sigma_T^2,\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{d\\langle Th\\rangle}{dt}\n",
        "=\n",
        "R\\langle Th\\rangle\n",
        "+F_1\\langle h^2\\rangle\n",
        "-F_2\\langle T^2\\rangle\n",
        "-\\varepsilon\\langle Th\\rangle,\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\frac{d\\langle h^2\\rangle}{dt}\n",
        "=\n",
        "-2F_2\\langle Th\\rangle\n",
        "-2\\varepsilon\\langle h^2\\rangle\n",
        "+\\sigma_h^2,\n",
        "$$\n",
        "\n",
        "where $\\langle\\cdot\\rangle$ denotes ensemble mean.\n",
        "\n",
        "At equilibrium,\n",
        "\n",
        "$$\n",
        "\\langle T^2\\rangle\n",
        "=\n",
        "\\frac{\n",
        "(F_1F_2-\\varepsilon R+\\varepsilon^2)\\sigma_T^2\n",
        "+F_1^2\\sigma_h^2\n",
        "}{\n",
        "2(-R+\\varepsilon)(F_1F_2-R\\varepsilon)\n",
        "},\n",
        "$$\n",
        "\n",
        "$$\n",
        "\\langle h^2\\rangle\n",
        "=\n",
        "\\frac{\n",
        "F_2^2\\sigma_T^2\n",
        "+(F_1F_2-\\varepsilon R+R^2)\\sigma_h^2\n",
        "}{\n",
        "2(-R+\\varepsilon)(F_1F_2-R\\varepsilon)\n",
        "}.\n",
        "$$\n",
        "\n",
        "Therefore `T_std` and `h_std` are the square roots of these equilibrium variances."
      ]
    },
