par_load#

Load a pre-fitted RO parameter set from the CRO parameter library.

Syntax#

[ ]:

par = par_load(data_name, RO_type)

Description#

par_load(data_name, RO_type) loads pre-fitted RO parameters from observational data or CMIP6 historical simulations for one of eight predefined RO types.

The parameter library uses:

  • T: detrended SST anomalies averaged over Niño3.4 (5°S–5°N, 170°–120°W)

  • h: detrended 20 °C isotherm-depth anomalies averaged over the equatorial Pacific (5°S–5°N, 120°E–80°W)

RO_type#

Eight predefined parameter-library RO types are supported:

  1. Linear-White-Additive

  2. Linear-White-Multiplicative

  3. Nonlinear-White-Additive

  4. Nonlinear-White-Multiplicative

  5. Seasonal-Linear-White-Additive

  6. Seasonal-Linear-White-Multiplicative

  7. Seasonal-Nonlinear-White-Additive

  8. Seasonal-Nonlinear-White-Multiplicative

Their equations are:

Linear-White-Additive

\[\frac{dT}{dt}=RT+F_1h+\sigma_Tw_T,\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h+\sigma_hw_h.\]

Linear-White-Multiplicative

\[\frac{dT}{dt}=RT+F_1h+\sigma_Tw_T(1+BT),\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h+\sigma_hw_h.\]

Nonlinear-White-Additive

\[\frac{dT}{dt}=RT+F_1h+b_TT^2-c_TT^3+d_TTh+\sigma_Tw_T,\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h-b_hT^2+\sigma_hw_h.\]

Nonlinear-White-Multiplicative

\[\frac{dT}{dt}=RT+F_1h+b_TT^2-c_TT^3+d_TTh+\sigma_Tw_T(1+BT),\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h-b_hT^2+\sigma_hw_h.\]

Seasonal-Linear-White-Additive

\[\frac{dT}{dt}= \left(R+R_a\sin(\omega t+\phi_a)\right)T+F_1h+\sigma_Tw_T,\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h+\sigma_hw_h.\]

Seasonal-Linear-White-Multiplicative

\[\frac{dT}{dt}= \left(R+R_a\sin(\omega t+\phi_a)\right)T+F_1h+\sigma_Tw_T(1+BT),\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h+\sigma_hw_h.\]

Seasonal-Nonlinear-White-Additive

\[\frac{dT}{dt}= \left(R+R_a\sin(\omega t+\phi_a)\right)T +F_1h+b_TT^2-c_TT^3+d_TTh+\sigma_Tw_T,\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h-b_hT^2+\sigma_hw_h.\]

Seasonal-Nonlinear-White-Multiplicative

\[\frac{dT}{dt}= \left(R+R_a\sin(\omega t+\phi_a)\right)T +F_1h+b_TT^2-c_TT^3+d_TTh+\sigma_Tw_T(1+BT),\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h-b_hT^2+\sigma_hw_h.\]

Output#

par contains the loaded CRO parameters.

  • For a single dataset/model: 16×1 cell array.

  • For data_name = "CMIP6-historical-all": 16×48 cell array, with parameters in rows and CMIP6 models in columns.

The parameter library contains only the predefined eight RO types. For another RO type or another data source, use RO_fitting.

Parameter values depend on the RO type used during fitting. Use parameters fitted for the same RO type that will be used in the solver whenever possible.

RO_solver_analytic#

Analytical trajectory solution for the linear-white-additive RO.

Syntax#

[ ]:

[T, h] = RO_solver_analytic(par, IC, N, NE)
[T, h] = RO_solver_analytic(par, IC, N, NE, dt)
[T, h] = RO_solver_analytic(par, IC, N, NE, dt, saveat)
[T, h] = RO_solver_analytic(par, IC, N, NE, dt, saveat, savemethod)
[T, h] = RO_solver_analytic(par, IC, N, NE, dt, saveat, savemethod, noise_custom)
[T, h, noise] = RO_solver_analytic(...)

Description and inputs#

RO_solver_analytic returns analytical trajectories of T and h for the linear-white-additive RO.

par is the standard 16-element parameter cell array. All elements are scalar, but only

  • R

  • F1

  • F2

  • epsilon

  • sigma_T

  • sigma_h

are used. The remaining entries may be unused values such as [] or NaN.

Other inputs:

  • IC: [T0, h0]

  • N: simulation length in months

  • NE: number of ensembles

  • dt: numerical time step in months (default 0.1)

  • saveat: output interval (default 1.0)

  • savemethod: "sampling" or "mean" (default "sampling")

  • noise_custom: scalar seed or (NT-1)×4 noise matrix

For noise_custom, only the first two columns are used by the analytical linear-white-additive solution; columns 3–4 are retained only for consistency with RO_solver. User-specified noise must be Gaussian white noise with zero mean and unit variance. The same supplied realization is used for each ensemble member.

Outputs#

  • T: NT×NE

  • h: NT×NE

  • noise: (NT_internal-1)×4×NE

Analytical solution#

The linear-white-additive RO is

\[\frac{dT}{dt}=RT+F_1h+\sigma_Tw_T,\]
\[\frac{dh}{dt}=-F_2T-\varepsilon h+\sigma_hw_h.\]

With initial conditions \(T_0\) and \(h_0\), define

\[\lambda_r=\frac{R-\varepsilon}{2},\]
\[\omega=\frac{\sqrt{4F_1F_2-(R+\varepsilon)^2}}{2}.\]

Then

\[\begin{split}\begin{aligned} T(t)=e^{\lambda_rt}\Bigg[ &T_0\left(\cos\omega t+\frac{R+\varepsilon}{2\omega}\sin\omega t\right) +h_0\frac{F_1}{\omega}\sin\omega t \\ &+\int_0^t e^{-\lambda_r\tau} \left\{ \sigma_Tw_T(\tau)\cos[\omega(t-\tau)] +\sigma_Tw_T(\tau)\frac{R+\varepsilon}{2\omega}\sin[\omega(t-\tau)] +\sigma_hw_h(\tau)\frac{F_1}{\omega}\sin[\omega(t-\tau)] \right\}\,d\tau \Bigg], \end{aligned}\end{split}\]

and

\[\begin{split}\begin{aligned} h(t)=e^{\lambda_rt}\Bigg[ &-T_0\frac{F_2}{\omega}\sin\omega t +h_0\left(\cos\omega t-\frac{R+\varepsilon}{2\omega}\sin\omega t\right) \\ &+\int_0^t e^{-\lambda_r\tau} \left\{ \sigma_hw_h(\tau)\cos[\omega(t-\tau)] -\sigma_hw_h(\tau)\frac{R+\varepsilon}{2\omega}\sin[\omega(t-\tau)] -\sigma_Tw_T(\tau)\frac{F_2}{\omega}\sin[\omega(t-\tau)] \right\}\,d\tau \Bigg]. \end{aligned}\end{split}\]

RO_std_analytic#

Analytical equilibrium standard deviations for the linear-white-additive RO.

Syntax#

[ ]:

[T_std, h_std] = RO_std_analytic(par)

Description#

RO_std_analytic(par) returns the analytical standard deviations of T and h for the linear-white-additive RO.

par is the standard 16-element scalar parameter cell array.

Outputs#

  • T_std: scalar standard deviation of T

  • h_std: scalar standard deviation of h

More about#

The second-order moments satisfy

\[\frac{d\langle T^2\rangle}{dt} = 2R\langle T^2\rangle +2F_1\langle Th\rangle +\sigma_T^2,\]
\[\frac{d\langle Th\rangle}{dt} = R\langle Th\rangle +F_1\langle h^2\rangle -F_2\langle T^2\rangle -\varepsilon\langle Th\rangle,\]
\[\frac{d\langle h^2\rangle}{dt} = -2F_2\langle Th\rangle -2\varepsilon\langle h^2\rangle +\sigma_h^2,\]

where \(\langle\cdot\rangle\) denotes ensemble mean.

At equilibrium,

\[\langle T^2\rangle = \frac{ (F_1F_2-\varepsilon R+\varepsilon^2)\sigma_T^2 +F_1^2\sigma_h^2 }{ 2(-R+\varepsilon)(F_1F_2-R\varepsilon) },\]
\[\langle h^2\rangle = \frac{ F_2^2\sigma_T^2 +(F_1F_2-\varepsilon R+R^2)\sigma_h^2 }{ 2(-R+\varepsilon)(F_1F_2-R\varepsilon) }.\]

Therefore T_std and h_std are the square roots of these equilibrium variances.

RO_BWJ#

Compute the BWJ index of the RO.

Syntax#

[ ]:

BWJ = RO_BWJ(par)

Description#

The BWJ index is

\[BWJ= \frac{R-\varepsilon}{2} +i\sqrt{F_1F_2-\frac{(R+\varepsilon)^2}{4}}.\]

par is the standard 16-element scalar CRO parameter cell array. Only R, F1, F2, and epsilon are used; the remaining elements are ignored.
