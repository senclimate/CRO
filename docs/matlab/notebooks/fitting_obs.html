CRO fitting with observation#

This tutorial illustrates how to use the mCRO to estimate RO parameters from the observations

This notebook was contributed by Soong-Ki Kim.

RO Parameter Fitting Usage#

par_fitted = RO_fitting(T, h, par_option_T, par_option_h, par_option_noise)

Input T and h Time Series#

  • T and h are input timeseries used for the fitting.

  • T and h must be 1D time series arrays with a uniform time step.

Specifiying RO Type#

These options define the RO model type used for fitting.

  • par_option_T specifies the linear and nonlinear terms in dT/dt

  • par_option_h specifies the linear and nonlinear terms in dh/dt

  • par_option_noise specifies the noise type

The following example shows how to set the RO type as linear-white-additive RO for the fitting.

par_option_T = struct(“R”,1,”F1”,1,”b_T”,0,”c_T”,0,”d_T”,0) par_option_h = struct(“F2”,1,”epsilon”,1,”b_h”,0)

  • For keys in par_option_T and par_option_h, allowed values are:

    • 0 — Do not estimate

    • 1 — Estimate only the annual mean

    • 3 — Estimate annual mean + annual seasonality

    • 5 — Estimate annual mean + annual + semi-annual seasonality

par_option_noise = struct(“T”,”white”,”h”,”white”,”T_type”,”multiplicative”)

  • Valid options for \(T\) and \(h\) are:

    • “white”: white noise forcing

    • “red”: red noise forcing

  • Both \(T\) and \(h\) must use the same noise type; otherwise, an error is raised.

  • Valid options for T-type (noise structure for \(T\)) are:

    • “additive”: T noise forcing is additive

    • “multiplicative”: T noise forcing is multiplicative

    • “multiplicative-H”: T noise forcing is Heaviside based-multiplicative noise

Fitting RO to the observation/reanalysis#

Load observed ENSO time series from ORAS5#

We load monthly Niño3.4 SST anomalies and equatorial Pacific Warm Water Volume (WWV; stored as Hm in the NetCDF file) from ORAS5.

The Python version of CRO uses pyCRO.ROdata_load(name=”ORAS5”). The MATLAB version does not include an equivalent convenience loader, so the NetCDF file is loaded manually.

The ORAS5 data file used here is “CROdata_timeseries_oras5.nc” in the “/Data” folder of the MATLAB CRO package.

Type Linear-White-Additive#

Fit linear RO with white and additive noise

\(\displaystyle \frac{dT}{dt}=RT+F_1h+\sigma_Tw_T\)

\(\displaystyle \frac{dh}{dt}=-F_2T-\varepsilon h+\sigma_hw_h\)

[4]:

par_option_T=struct("R",1,"F1",1,"b_T",0,"c_T",0,"d_T",0);
par_option_h=struct("F2",1,"epsilon",1,"b_h",0);
par_option_noise=struct("T","white","h","white","T_type","additive");


par_obs_LWA=RO_fitting(T_oras5,h_oras5,par_option_T,par_option_h,par_option_noise);

Type Seasonal-Linear-White-Additive#

Fit seasonal linear RO with white and additive noise

\(\displaystyle \frac{dT}{dt}=(R+R_a\sin(\omega t+\phi_{R}))T+(F_1+F_{1a}\sin(\omega t+\phi_{F_1}))h+\sigma_Tw_T\)

\(\displaystyle \frac{dh}{dt}=-(F_2+F_{2a}\sin(\omega t+\phi_{F_2}))T- (\varepsilon+\varepsilon_a\sin(\omega t+\phi_{\varepsilon})) h+\sigma_hw_h\)

Type Seasonal-Nonlinear-White-Additive#

Fit seasonal nonlinear RO with white and additive noise

\(\displaystyle \frac{dT}{dt}=R T+F_1h+b_TT^2-c_TT^3+d_TTh+\sigma_Tw_T\)

\(\displaystyle \frac{dh}{dt}=-F_2T-\varepsilon h-b_hT^2+\sigma_hw_h\)

** here we include seasonal cycle in all determintic linear and nonlinear parameters

Advanced Usage (optional)#

RO_fitting also accepts optional fitting-method and input-time-step arguments:

par_fitted=RO_fitting(T,h,par_option_T,par_option_h,par_option_noise,method_fitting);

par_fitted=RO_fitting(T,h,par_option_T,par_option_h,par_option_noise,method_fitting,dt);

  • “LR-F”: linear regression using forward-difference tendencies.

  • “LR-C”: linear regression using central-difference tendencies.

  • “LR-F-MAC”: forward-difference linear regression with moment analytical constraints for T-noise parameters.

  • “MLE”: maximum likelihood estimation.

dt specifies the time interval of the input T and h series in months (default = 1.0). If method_fitting is omitted, CRO selects the default method for the specified RO type.

Local helper functions#

These helper functions replace convenience functions used by the Python notebook.

[15]:

function S=seasonal_statistic(X,stat_name)
% Return [12 x ensemble] seasonal statistics, assuming January is the first sample.


if isvector(X)
    X=X(:);
end


nMember=size(X,2);
S=nan(12,nMember);
for m=1:12
    idx=m:12:size(X,1);
    for im=1:nMember
        x=X(idx,im);
        switch lower(stat_name)
            case "std"
                S(m,im)=std(x,0,'omitnan');
            otherwise
                error("Unknown statistic: %s",stat_name)
        end
    end
end
end


function h=plot_mean_spread(x,Y,label_text,line_color)
% Plot ensemble mean and 10th-90th percentile spread.


if isvector(Y)
    Y=Y(:);
end


mu=mean(Y,2,'omitnan');
lo=prctile(Y,10,2);
hi=prctile(Y,90,2);


fill([x(:);flipud(x(:))],[lo(:);flipud(hi(:))],line_color, ...
    'FaceAlpha',0.20,'EdgeColor','none','HandleVisibility','off');
hold on
h=plot(x,mu,'Color',line_color,'LineWidth',1.8,'DisplayName',label_text);
end


function plot_RO_par_comparison(par_list,label_list)
% MATLAB replacement for pyCRO.plot_RO_par used in this tutorial.
% Reconstruct monthly deterministic parameters from scalar/seasonal CRO coefficients.
% BJ is defined as BJ = 0.5*(R + epsilon).


months=1:12;
month_label={'J','F','M','A','M','J','J','A','S','O','N','D'};


% Panel definitions: BJ, R, epsilon, F1, F2, b_T, c_T, d_T, b_h
panel_par={0,1,4,2,3,5,6,7,8};
panel_title={'BJ','R','\epsilon','F_1','F_2','b_T','c_T','d_T','b_h'};
panel_unit={'month^{-1}','month^{-1}','month^{-1}', ...
    'K m^{-1} month^{-1}','m K^{-1} month^{-1}', ...
    'K^{-1} month^{-1}','K^{-2} month^{-1}', ...
    'm^{-1} month^{-1}','K^{-2} m month^{-1}'};


figure;
tiledlayout(3,3,'TileSpacing','compact','Padding','compact');


for ipanel=1:9
    nexttile
    hold on


    for imodel=1:numel(par_list)
        par=par_list{imodel};


        if panel_par{ipanel}==0
            R_month=arrayfun(@(m) monthly_parameter_value(par{1},m),months);
            epsilon_month=arrayfun(@(m) monthly_parameter_value(par{4},m),months);
            y=0.5*(R_month+epsilon_month);
        else
            k=panel_par{ipanel};
            y=arrayfun(@(m) monthly_parameter_value(par{k},m),months);
        end


        plot(months,y,'-o','LineWidth',1.3,'MarkerSize',3.5, ...
            'DisplayName',label_list{imodel});
    end


    xlim([0.5 12.5])
    xticks(1:12)
    xticklabels(month_label)
    ylabel(sprintf('%s (%s)',panel_title{ipanel},panel_unit{ipanel}), ...
        'Interpreter','tex')
    grid on


    if ipanel==9
        legend('Location','best','FontSize',8)
    end
end
end


function y=monthly_parameter_value(v,month_index)
% Evaluate a CRO parameter at one calendar month.
% []/NaN parameters are plotted as zero, matching the Python tutorial display.


if isempty(v) || all(~isfinite(v))
    y=0;
    return
end


v=v(:).';
t=(month_index-1);
w=2*pi/12;


switch numel(v)
    case 1
        y=v(1);
    case 3
        y=v(1)+v(2)*sin(w*t+v(3));
    case 5
        y=v(1)+v(2)*sin(w*t+v(3))+v(4)*sin(2*w*t+v(5));
    otherwise
        idx=mod(month_index-1,numel(v))+1;
        y=v(idx);
end
end
