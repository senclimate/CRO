CRO reproduces the ENSO characteristics in observations#

This tutorial demonstrates how to use mCRO to calibrate the Recharge Oscillator (RO) model against observed ENSO variability and evaluate how well the fitted stochastic RO model reproduces key characteristics of the observed ENSO system.

Starting from observed Niño3.4 SST anomalies and Warm Water Volume (WWV), we will

  • fit the stochastic Recharge Oscillator parameters,

  • generate stochastic large ensemble simulations,

  • compare the simulated and observed ENSO statistics, and

  • evaluate whether the model reproduces important dynamical characteristics such as seasonal synchronization, nonlinear asymmetry, persistence, phase relationships, and spectral peaks.

Although the Recharge Oscillator is a highly idealized model, this example illustrates that it captures many of the essential features of observed ENSO.

This notebook was contributed by Soong-Ki Kim.

Contacts: Sen Zhao zhaos@hawaii.edu, Soong-Ki Kim soongkim@postech.ac.kr

Load Observed Nino3.4 and WWV time series#

We begin by loading monthly observations of

  • Niño3.4 SST anomaly, representing the eastern-central tropical Pacific sea surface temperature anomalies that define ENSO, and

  • Warm Water Volume (WWV), representing the equatorial Pacific upper-ocean heat content, which provides the “memory” of the ENSO system.

The observations are taken from the ORAS5 ocean reanalysis. These two variables form the state variables of the Recharge Oscillator model.

The ORAS5 ENSO dataset is included in the “/Data” folder of the MATLAB CRO package as “CROdata_timeseries_oras5.nc”.

Note that the Python version of CRO (pyCRO) provides the pyCRO.ROdata_load function for directly loading this dataset. The MATLAB version does not include an equivalent data-loading function, so the NetCDF file is loaded manually below.

[2]:

%   Nino34 : monthly Niño3.4 SST anomaly
%   WWV    : monthly Warm Water Volume / thermocline-depth anomaly


fpath=pwd+"/Data/"+"CROdata_timeseries_oras5.nc"; % replace with your file path if needed
Nino34=ncread(fpath,'Nino34'); % load T (Niño3.4 SST anomaly)
WWV=ncread(fpath,'Hm');        % load h (WWV; stored as Hm in the NetCDF file)
time_raw=ncread(fpath,'time'); % days since 1979-01-01


% Ensure column-vector format for CRO fitting
Nino34=Nino34(:);
WWV=WWV(:);
time_oras5=datetime(1979,1,1)+days(time_raw(:));


ncdisp(fpath)

Fit the observed Recharge Oscillator using mCRO#

The Recharge Oscillator contains a small number of physically interpretable parameters describing

  • ENSO linear RO parameters (R and epsilon, F1 and F2)

  • Nonlinear feedbacks (b_T, c_T, d_T and b_h)

  • Stochastic noise (red or white, addtive or multiplicative)

check details at https://senclimate.github.io/CRO/matlab/notebooks/model_parameters.html

Here we estimate these parameters directly from the observed Niño3.4 and WWV time series.

The fitted parameter set will later be used to generate stochastic simulations of ENSO.

[4]:

par_option_T=struct("R",3,"F1",3,"b_T",3,"c_T",3,"d_T",3);
par_option_h=struct("F2",3,"epsilon",3,"b_h",3);
par_option_noise=struct("T","red","h","red","T_type","additive");


par_obs_fit=RO_fitting(Nino34,WWV,par_option_T,par_option_h,par_option_noise);
disp(par_obs_fit)

RO stochastic simulations#

Using the fitted parameters, we integrate the stochastic Recharge Oscillator forward in time.

To obtain robust climate statistics, we generate a 100-member ensemble, with each member spanning 200 years. The long ensemble allows internal variability to be sampled while preserving the observed dynamics estimated from the fitting procedure.

[5]:

IC=[0;0];
N=12*200;
NE=100;


[Nino34_RO,WWV_RO]=RO_solver(par_obs_fit,IC,N,NE);

Seasonal varying standard deviation#

One hallmark of ENSO is seasonal synchronization: ENSO events tend to reach their maximum amplitude during boreal winter.

Here we compare the monthly standard deviation of Niño3.4 between observations and the stochastic simulations. A successful model should reproduce both the timing and magnitude of this seasonal modulation.

[6]:

obs_seaSD=seasonal_statistic(Nino34,"std");
RO_seaSD=seasonal_statistic(Nino34_RO,"std");


month_name={'Jan','Feb','Mar','Apr','May','Jun','Jul','Aug','Sep','Oct','Nov','Dec'};


figure;
hold on
plot(1:12,obs_seaSD,'k-','LineWidth',1.8,'DisplayName','ORAS5');
plot_ensemble_spread(1:12,RO_seaSD,'RO',[]);
xlim([1 12])
xticks(1:12)
xticklabels(month_name)
ylabel('Nino34 seasonal standard deviation (°C)')
xlabel('Calendar Month')
title('CRO simulates ENSO seasonal synchronization')
legend('Location','best')

Seasonal varying skewness#

ENSO is intrinsically nonlinear. Strong El Niño events generally exhibit larger amplitudes than La Niña events, producing a positive skewness in Niño3.4 SST anomalies.

This section compares the seasonal evolution of skewness between observations and the stochastic simulations to assess whether the fitted model captures this important asymmetry.

Autocorrelation / Cross correlation#

Autocorrelation measures the persistence of Niño3.4 SST anomalies, while cross-correlation between Niño3.4 and WWV reveals the recharge-discharge cycle that underlies ENSO dynamics.

A realistic Recharge Oscillator should reproduce

  • the observed persistence of SST anomalies,

  • WWV leading SST during event growth, and

  • SST leading WWV during the discharge phase.

[8]:

maxlags=36;
[lags,obs_acf,obs_ccf]=ensemble_xcorr(Nino34,WWV,maxlags);
[~,RO_acf,RO_ccf]=ensemble_xcorr(Nino34_RO,WWV_RO,maxlags);

ENSO spectrum analysis#

Finally, we examine the frequency characteristics of the simulated ENSO variability using Thomson’s multitaper spectral estimator.

The observed ENSO spectrum is characterized by

  • a dominant peak near 2.5–5.5 years (``fE``), corresponding to the intrinsic ENSO oscillation, and

  • weaker combination modes (1-fE and 1+fE) produced by interactions between the annual cycle and ENSO.

Comparing the simulated and observed spectra provides a stringent test of whether the fitted stochastic model reproduces the dominant timescales of ENSO variability.

Reference: Stuecker, M. F., Timmermann, A., Jin, F.-F., McGregor, S., & Ren, H.-L. (2013). A combination mode of the annual cycle and the El Niño/Southern Oscillation. Nature Geoscience, 6(7), 540–544. https://doi.org/10.1038/ngeo1826

Summary#

In this tutorial we

  • fitted the Recharge Oscillator to observed Niño3.4 and WWV,

  • generated long stochastic ensemble simulations,

  • reproduced the observed seasonal synchronization of ENSO,

  • captured the nonlinear asymmetry between El Niño and La Niña,

  • recovered the observed recharge-discharge relationship between SST and WWV, and

  • reproduced the dominant spectral characteristics of ENSO.

This example demonstrates that the stochastic Recharge Oscillator provides a compact yet physically interpretable framework for understanding and simulating the essential dynamics of ENSO.

Beyond reproducing observations, mCRO provides a powerful framework for numerical experiments. By systematically perturbing individual RO parameters—such as the ocean-atmosphere coupling strength, damping, nonlinear feedbacks, or stochastic forcing—you can directly investigate how each physical process influences ENSO amplitude, periodicity, predictability, seasonal phase locking, and nonlinear asymmetry. Such parameter perturbation experiments offer an intuitive and computationally efficient way to understand the mechanisms controlling ENSO dynamics and to test hypotheses about climate variability.

Local helper functions#

These helper functions replace convenience functions used by the Python notebook.

[11]:

function S=seasonal_statistic(X,stat_name)
% Return [12 x ensemble] seasonal statistics, assuming the series starts in January.


if isvector(X)
    X=X(:);
end


nMember=size(X,2);
S=nan(12,nMember);
for m=1:12
    idx=m:12:size(X,1);
    for im=1:nMember
        x=X(idx,im);
        switch lower(stat_name)
            case "std"
                S(m,im)=std(x,0,'omitnan');
            case "skewness"
                x=x(isfinite(x));
                if numel(x)>=3
                    S(m,im)=skewness(x,0);
                end
            otherwise
                error("Unknown statistic: %s",stat_name)
        end
    end
end
end


function h=plot_ensemble_spread(x,Y,label_text,line_color)
% Plot median and 10th-90th percentile spread across ensemble dimension.


med=median(Y,2,'omitnan');
lo=prctile(Y,10,2);
hi=prctile(Y,90,2);


if isempty(line_color)
    h=plot(x,med,'LineWidth',1.8,'DisplayName',label_text);
    c=h.Color;
else
    c=line_color;
    h=plot(x,med,'Color',c,'LineWidth',1.8,'DisplayName',label_text);
end


fill([x(:);flipud(x(:))],[lo(:);flipud(hi(:))],c, ...
    'FaceAlpha',0.15,'EdgeColor','none','HandleVisibility','off');
uistack(h,'top')
end


function [lags,acf,ccf]=ensemble_xcorr(T,H,maxlags)
% ACF of T and cross-correlation between T and H for each ensemble member.
% Positive cross-correlation lag is plotted as T leading H, matching the tutorial labels.


if isvector(T), T=T(:); end
if isvector(H), H=H(:); end


nMember=size(T,2);
lags=(-maxlags:maxlags).';
acf=nan(numel(lags),nMember);
ccf=nan(numel(lags),nMember);


for im=1:nMember
    t=T(:,im);
    h=H(:,im);
    good=isfinite(t) & isfinite(h);
    t=t(good);
    h=h(good);
    t=t-mean(t,'omitnan');
    h=h-mean(h,'omitnan');
    acf(:,im)=xcorr(t,t,maxlags,'coeff');
    ccf(:,im)=xcorr(t,h,maxlags,'coeff');
end
end


function [freq,P,SIG]=ensemble_pmtm(X,NW,fs)
% Multitaper PSD and AR(1) red-noise 95% significance spectrum
% for each ensemble member.


if isvector(X)
    X=X(:);
end


nMember=size(X,2);
P=[];
SIG=[];
freq=[];


for im=1:nMember
    x=X(:,im);
    x=x(isfinite(x));
    x=x-mean(x,'omitnan');


    % Multitaper power spectrum
    [pxx,f]=pmtm(x,NW,[],fs);


    % Lag-1 autocorrelation
    r1=corr(x(1:end-1),x(2:end));


    % AR(1) red-noise background spectrum
    rednoise=var(x,1) .* ...
        (1-r1^2) ./ ...
        (1+r1^2-2*r1*cos(2*pi*f/fs));


    % Scale AR(1) spectrum to the variance represented by the PMTM spectrum
    rednoise=rednoise .* ...
        (trapz(f,pxx)/trapz(f,rednoise));


    % 95% significance level using approximately 2*NW degrees of freedom
    dof=2*NW;
    sig95=rednoise .* chi2inv(0.95,dof)/dof;


    if isempty(P)
        freq=f;
        P=nan(numel(f),nMember);
        SIG=nan(numel(f),nMember);
    end


    P(:,im)=pxx;
    SIG(:,im)=sig95;
end
end


function h=plot_spectrum_spread(freq,P,label_text,line_color)
% Plot median PSD and 5th-95th percentile ensemble spread.


med=median(P,2,'omitnan');
lo=prctile(P,5,2);
hi=prctile(P,95,2);


if isempty(line_color)
    h=loglog(freq,med,'LineWidth',1.5,'DisplayName',label_text);
    c=h.Color;
else
    c=line_color;
    h=loglog(freq,med,'Color',c,'LineWidth',1.5,'DisplayName',label_text);
end


valid=freq>0 & lo>0 & hi>0;
fill([freq(valid);flipud(freq(valid))],[lo(valid);flipud(hi(valid))],c, ...
    'FaceAlpha',0.15,'EdgeColor','none','HandleVisibility','off');
set(gca,'XScale','log','YScale','log')
uistack(h,'top')
end


function patch_band(xrange,yl,alpha_value)
patch([xrange(1) xrange(2) xrange(2) xrange(1)], ...
      [yl(1) yl(1) yl(2) yl(2)], ...
      [0.5 0.5 0.5], ...
      'FaceAlpha',alpha_value,'EdgeColor','none','HandleVisibility','off');
end
